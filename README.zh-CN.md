# arona-blog-api

🌍 [English](./README.md) | 中文

这是Aronaの小屋 网站的后端服务

功能还在逐步开发中……

## 项目架构

框架：Midway.js 3

语言：Typescript 5.9.3

服务器：Koa 2

通信协议：HTTP

缓存：Redis 8.2.3

数据库：MongoDB 7.0.28

本地文件存储：Minio 2025.4.22

打包工具：gulp

## 项目部署

```sh
  yarn install
```

### 编译和开发热重载

```sh
  yarn dev
```

### 类型检查、编译和生产环境打包

```sh
  yarn build
```

### 类型检查

```sh
  yarn lint
```
