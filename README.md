# arona-blog-api

🌍 English | [中文](./README.zh-CN.md)

This is the backend service for a personal website built by a BA player.
Features are still being developed gradually...

## Project Architecture

Framework: Midway.js 3

Language: TypeScript 5.9.3

Server: Koa 2

Communication Protocol: HTTP

Cache: Redis 8.2.3

Database: MongoDB 7.0.28

Local File Storage: Minio 2025.4.22

Build Tool: Gulp

## Project Deployment

```sh
  yarn install
```

### Compilation and Development Hot Reload

```sh
  yarn dev
```

### Type Checking, Compilation and Production Build

```sh
  yarn build
```

### Type Checking

```sh
  yarn lint
```
